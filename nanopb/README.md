# nanopb runtime

Decoder runtime from [nanopb](https://github.com/nanopb/nanopb) 0.4.9.2,
copied unmodified. Licensed under the zlib license in `LICENSE.txt`.

Only the files needed for decoding are included. Code generated from
`../proto` must be produced by the generator from the same nanopb release;
see `../proto/generate.sh`.
